# Minecraft Launcher

Лаунчер **Minecraft Java Edition** для Windows: сборки с модами, Modrinth, выбор Java, офлайн-никнейм.

**Скачать:** [Releases](https://github.com/SoniWer/minecraft-launcher/releases) → последний релиз → **`MinecraftLauncher.exe`**.

Исходный код открыт в этом репозитории (Python). Готовый лаунчер — только EXE из Releases.

---

## Установка

1. Скачайте **`MinecraftLauncher.exe`** из [Releases](https://github.com/SoniWer/minecraft-launcher/releases).
2. Положите в любую папку (например `C:\Games\MinecraftLauncher\`).
3. Запустите. Если SmartScreen предупреждает: **Подробнее** → **Выполнить в любом случае**.

При первом запуске рядом с EXE появятся `builds/` и `settings.json`.

**Python не нужен** — только EXE.

---

## Как пользоваться

1. **Сборка** — «Основная» или новая (**+**).
2. **Никнейм** — любой офлайн-ник.
3. **Версия MC** — из списка (**★** — избранные версии вверху).
4. **Загрузчик** — Vanilla или Fabric / Forge / NeoForge / Quilt для модов.
5. **Java** — «Авто» или **Скачать Java** в утилитах.
6. **▶ Играть** — при первом запуске скачается Minecraft (нужен интернет).

**Моды:** Modrinth, список модов, перетащите **.jar** на окно лаунчера.

**Бэкап:** перед modpack и «Обновить все моды» — ZIP в `backups/`. Вручную: **Экспорт** / **Импорт**.

## Папки рядом с EXE

| Папка / файл   | Назначение              |
|----------------|-------------------------|
| `builds/`      | Сборки, моды, миры      |
| `backups/`     | Автобэкапы ZIP          |
| `java/`        | Скачанная Java          |
| `settings.json`| Настройки лаунчера      |

Кнопки **Папки сборки** в лаунчере открывают нужные каталоги.

## Частые вопросы

**Где миры и моды?**  
`builds/ИМЯ-СБОРКИ/game/`

**Можно играть по сети?**  
Офлайн-ник. LAN — «Открыть для сети» в игре или VPN.

**Антивирус ругается?**  
Добавьте папку с EXE в исключения (сборка без подписи Microsoft).
