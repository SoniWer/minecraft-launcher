# Разработка и сборка

Для тех, кто клонирует репозиторий с GitHub и меняет код.

## Требования

- Windows 10/11
- Python 3.12+ (рекомендуется)
- Git

## Клонирование

```bash
git clone https://github.com/ВАШ_НИК/minecraft-launcher.git
cd minecraft-launcher
pip install -r requirements.txt
python launcher.py
```

## Структура проекта

| Файл / папка | Назначение |
|--------------|------------|
| `launcher.py` | Главное окно лаунчера |
| `builds.py` | Сборки и профили |
| `modrinth.py`, `modrinth_ui.py` | API и окно Modrinth |
| `mods_ui.py` | Менеджер модов |
| `java_manager.py`, `java_download.py` | Java |
| `deps_check.py` | Проверка библиотек при старте |
| `auto_backup.py` | Автобэкапы |
| `build_exe.ps1` | Локальная сборка EXE |
| `.github/workflows/` | CI и релизы на GitHub |

## Локальная сборка EXE

```powershell
.\build_exe.ps1
```

EXE появится в корне проекта (не коммитится в git — только в Releases).
