# Установка для игроков (Windows)

Инструкция для тех, кто скачал лаунчер с **GitHub → Releases**, без Python.

## Что скачать

1. Откройте страницу репозитория на GitHub.
2. Справа раздел **Releases** (или «Релизы»).
3. Откройте последний релиз (например `v1.0.0`).
4. В блоке **Assets** скачайте **`MinecraftLauncher.exe`**.

Другие файлы в релизе не нужны — только EXE.

## Первый запуск

1. Создайте папку, например `C:\Games\MinecraftLauncher\`.
2. Перенесите туда `MinecraftLauncher.exe`.
3. Запустите двойным щелчком.
4. Если Windows SmartScreen предупреждает: **Подробнее** → **Выполнить в любом случае**.

При первом запуске рядом с EXE появятся:

- `builds/` — ваши сборки (моды, миры, конфиг);
- `settings.json` — настройки лаунчера.

## Быстрый старт в лаунчере

1. **Сборка** — оставьте «Основная» или создайте новую (**+**).
2. **Никнейм** — любой офлайн-ник.
3. **Версия MC** — выберите из списка (кнопка **★** закрепляет избранные версии вверху).
4. **Загрузчик** — Vanilla или Fabric / Forge / NeoForge / Quilt для модов.
5. **Java** — «Авто» или **Скачать Java** в утилитах.
6. **▶ Играть** — при первом разе скачается Minecraft (нужен интернет).

## Java для Minecraft

| Версия Minecraft | Нужная Java |
|------------------|-------------|
| 1.16 и ниже      | 8           |
| 1.17 – 1.20.4    | 17          |
| 1.20.5 и новее   | 21          |

Лаунчер подскажет и может скачать Java кнопкой **Скачать Java**.

## Моды

- **Modrinth** — каталог модов, сборок, текстур, шейдеров.
- **Моды** — список установленных `.jar`, обновления, вкл./выкл.
- Перетащите файл **.jar** на окно лаунчера — он попадёт в `mods/` текущей сборки.

## Бэкапы

Перед установкой modpack или «Обновить все моды» лаунчер сохраняет ZIP в папку `backups/` рядом с EXE.

Ручной экспорт: **Экспорт** / **Импорт** в блоке «Утилиты».

## Частые вопросы

**Нужен ли Python?**  
Нет, только EXE из Releases.

**Где миры и моды?**  
В `builds/ИМЯ-СБОРКИ/game/` — кнопки «Папки сборки» в лаунчере.

**Можно играть по сети?**  
Офлайн-ник. Для LAN — «Открыть для сети» в игре или VPN (Radmin, Hamachi).

**Антивирус ругается?**  
Добавьте папку с EXE в исключения — сборка не подписана сертификатом Microsoft.
